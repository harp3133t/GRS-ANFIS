# Notebook Guide

Run notebooks from the project root or from this directory. The reproducibility notebooks auto-detect the project root by locating the local source files.

For the full manuscript-oriented workflow, see:

```text
reproducibility/README_reproducibility_notebooks.md
```

Start with `reproducibility/00_download_datasets.ipynb` on a fresh clone, then follow the execution order in the reproducibility README.

`01_main_performance.ipynb` is the older full 5-fold training workflow. It can take a long time and is not the primary manuscript table packaging entry point.
